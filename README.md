## 🎯 项目价值
本项目并非简易MNIST玩具分类模型，完整还原真实生物医药机器学习项目全流程：从原始GEO芯片数据到可落地集成模型，代码工程标准满足科研要求。

项目亮点：
| 维度 | 项目体现能力 |
|------|--------------|
| 数据工程 | 自研GEO SOFT格式解析器，而非仅调用`pd.read_csv`，适配真实脏数据 |
| 机器学习规范 | 杜绝数据泄露：特征筛选仅在交叉验证训练集内执行；训练/验证/测试集严格分离 |
| 模型多样性 | MLP、一维CNN、自编码器，搭配传统机器学习（SVM、随机森林、线性判别LDA），掌握各模型适用场景 |
| 可复现性 | 固定随机种子、完整预处理流水线序列化、模型断点保存 |
| 代码架构 | 模块化分层（数据→模型→训练→评估），无巨型单文件脚本 |
| 真实业务约束 | 仅500以内样本、180个特征，属于高维小样本难题；无海量数据兜底 |

## 🧬 研究问题与数据集
- **数据集**：[GSE25066](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE25066)（GPL96芯片平台）
- **样本量**：约500例乳腺癌患者
- **分类标签**：新辅助化疗后病理完全缓解（pCR）/ 残留病灶（RD）
- **特征**：原始54000个探针，经筛选保留180个有效致病基因
- **核心难点**：高维小样本（特征数远大于样本数）、潜在批次效应干扰

### 一键执行全流程
```bash
python main.py
```
流水线自动完成以下步骤：
1. 解析并预处理原始芯片数据
2. 超参数网格搜索（类别权重、权重衰减、dropout比例）
3. 训练MLP、CNN、自编码器+逻辑回归深度学习模型
4. 训练传统机器学习基线（SVM、随机森林、LDA）
5. 模型集成（加权平均 + 堆叠学习）
6. 生成评估图表、保存全部训练完成的模型

## 🔑 工程设计思路
### 1. 为什么给PyTorch模型封装sklearn兼容接口？
`MLPWrapper`、`AutoencoderClassifier` 继承sklearn基类`BaseEstimator`/`ClassifierMixin`。
深度学习模型可直接接入`StackingClassifier`、`cross_val_score`、网格搜索，无需额外编写适配胶水代码。

### 2. 为什么采用两阶段特征筛选（F检验→随机森林）？
单阶段过滤（如仅SelectKBest）无法捕捉特征间非线性关联；随机森林特征重要性可挖掘非线性依赖。
两阶段方案兼顾统计学筛选与模型感知筛选，**全部筛选过程仅在训练集执行**，彻底规避数据泄露。

### 3. 为什么使用温度缩放+阈值调优，而非默认0.5分类阈值？
医疗数据集多存在类别不平衡，固定0.5阈值效果很差。温度缩放校准模型预测概率；再基于验证集最大化F1分数寻找最优阈值，是临床机器学习标准方案，绝大多数学生项目都会忽略这一步。

### 4. 为什么保留早期单文件原型脚本？
直观展示代码重构全过程。面试官可对比原型文件`v19_updated_ae.py`与模块化正式版本，体现你不仅能写代码，更具备**工程化架构设计能力**。

### 5. 为什么不直接使用预训练模型或自动机器学习工具？
本数据集仅数百条领域专属基因表达数据，迁移学习增益极低。项目全程基于基础算法搭建：特征工程、传统基线、自定义网络，用于展示你对各类算法适用场景、底层原理的深度理解。
